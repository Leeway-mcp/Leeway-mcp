# Leeway brand kit

## Mark: "Drift"
Two sails heeled 8° by the wind over a hull. Leeway is a nautical word (a ship's drift under wind): the sails are the freedom, the hull is the limits, and the mainsail's mast and boom form an L. Flat, one colour, works from 16 px to a coin.

| File | Use |
|---|---|
| `creatives/brand/leeway-mark-gold.svg` | Master mark, vector, gold gradient |
| `creatives/brand/leeway-mark-white.svg` / `-black.svg` | One-colour versions (dark / light backgrounds, embossing) |
| `creatives/brand/leeway-mark-1024.png` | Mark, transparent PNG |
| `creatives/brand/leeway-logo-dark.png` | Horizontal logo for dark backgrounds (cream wordmark), transparent |
| `creatives/brand/leeway-logo-light.png` | Horizontal logo for light backgrounds (ink wordmark), transparent |
| `creatives/brand/x-avatar-400.png` (+ `@2x`) | X / Telegram avatar, circle-safe |
| `creatives/brand/x-header-1500x500.png` (+ `@2x`) | X header |
| `creatives/brand/brand.html` + `render.mjs` | Source: edit and re-render everything with `node render.mjs <playwright-dir>` |

Clear space around the mark: at least the hull height. Do not recolour the gradient, rotate the mark, add outlines or put it on busy photos.
