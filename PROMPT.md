## Проект

**AURUM MCP** — open-source MCP-сервер (Model Context Protocol), который даёт ИИ-агентам (Claude, Cursor, ChatGPT, любые MCP-клиенты) безопасный доступ к ончейн-экономике:

- live-цены, балансы кошельков, газ, данные о токенах;
- скан рисков смарт-контрактов (honeypot, mint-функции, концентрация холдеров);
- симуляция свапов перед исполнением;
- **x402-платежи**: агенты платят за API/данные микротранзакциями в USDC;
- **Policy Engine**: лимиты трат, allowlist контрактов, human-in-the-loop подтверждение. Агент не может потратить больше, чем ему разрешено.

Нарратив: *Agentic Economy*. Миллионы ИИ-агентов станут экономическими участниками, и им нужен «золотой стандарт» доступа к деньгам. Отсюда золото в айдентике.

Токен **$AUR** (концепт): стейкинг операторов MCP-нод, оплата премиум-тулов, governance. **xAUR** — застейканный AUR, получающий долю комиссий за tool-calls.

Слоган: **"Where AI Agents Meet On-Chain Value"**.

## Визуальный референс

Тёмный премиальный крипто-лендинг (референс «Metaverse / IIC»): чёрный фон, золото, синий свет, 3D-объекты из полированного золота. Мы делаем **свой** бренд в этой стилистике, а не копию.

### Ключевые паттерны

1. **Двухтональные заголовки**: начало белое, последние слоги/слово уходят в серый градиент («A New Standard for Agent *Finance*»).
2. **Лейблы секций**: `[ OVERVIEW ]`, золотые, моно, 11px, letter-spacing .2em.
3. **Уголки-скобки**: у карточек L-образные уголки 10px по углам + тонкие крестики `+` на стыках сетки.
4. **Кнопки**: primary — золотой градиент, тёмный текст, uppercase 12px, ✦ иконка; secondary — прозрачная, золотая рамка 1px.
5. **Свет**: тёплое медно-розовое свечение слева сверху в hero, синий вертикальный луч через глобус, золотое свечение в CTA.
6. **Сетка** 1180px max, гаттер 16px на мобиле.

3. **Ticker**: бесконечная бегущая строка с **live-ценами AI-токенов и мейджоров** (CoinGecko API, fallback на статичные данные): иконка, имя, тикер, цена, изменение за 24ч зелёным/красным.

Ниже две карточки: «MCP infrastructure» (вращающийся золотой квадрат-рамка) и «Agent intelligence» (золотое нейро-ядро с орбитами узлов).

12. **«Designed for Global Impact»**: стеклянный баннер. **«Step Into the Future»**: CTA с синим лучом, золотым светом и 3D-объектами по углам.
13. **«Expert Articles, Trends & Valuable Insights»**: 3 статьи в сетке с уголками, тег, автор, дата.
14. **Footer**: рамки с ромбами по углам, подписка на email, ссылки, соцсети, огромный полупрозрачный «AURUM» на фоне, тёплое свечение снизу.

## Технические требования

- Статический сайт без сборки (деплой на GitHub Pages / Vercel в один клик): `index.html`, `styles.css`, `js/*.js` (ES-модули), Three.js локально.
- Все 3D-сцены: `MeshPhysicalMaterial` золото (metalness 1, roughness .15–.25, clearcoat) + `RoomEnvironment` PMREM. Рендер только когда секция в viewport (IntersectionObserver), DPR ≤ 2.
- Анимации появления: fade/translate + blur при скролле, stagger. `prefers-reduced-motion` выключает тяжёлое движение.
- Адаптив: 1440 / 1024 / 768 / 375. На мобиле глобус под текстом, меню-бургер.
- Lighthouse: семантика, alt, aria, контраст, meta/OG-теги.
- Без внешних картинок: всё 3D процедурное, иконки инлайн-SVG.

## Критерии готовности

- На скриншоте 1440px страница визуально на уровне референса: глубина, свет, 3D-золото, аккуратная типографика.
- Нет горизонтального скролла на 375px.
- 60 fps на среднем ноутбуке, нет ошибок в консоли.
