## Проект

**Leeway MCP** — open-source MCP-сервер (Model Context Protocol), который даёт ИИ-агентам (Claude, Cursor, ChatGPT, любые MCP-клиенты) безопасный доступ к ончейн-экономике:

- live-цены, балансы кошельков, газ, данные о токенах;
- скан рисков смарт-контрактов (honeypot, mint-функции, концентрация холдеров);
- симуляция свапов перед исполнением;
- **x402-платежи**: агенты платят за API/данные микротранзакциями в USDC;
- **Policy Engine**: лимиты трат, allowlist контрактов, human-in-the-loop подтверждение. Агент не может потратить больше, чем ему разрешено.

- **Equity Rails** (фаза 4): управление **токенизированными акциями** (TSLAx, NVDAx и т.д. на Solana / Arbitrum / Base) под теми же мандатами, плюс **Parity Guard**: агент не купит токенизированную акцию дороже реальной биржевой цены (premium вне коридора 0.5% = блок). Также мандаты для акций: лимит на тикер, лимит на сектор, без плеча, торговля только в часы работы биржи, учёт дивидендов и сплитов.

### Бренд: почему LEEWAY

*Leeway* — свобода действий в заданных рамках. Это и есть продукт: агент сам торгует, платит и действует, но только в том пространстве, которое ему дал владелец. Не приватный ключ без ограничений и не поводок, который делает агента бесполезным. Слово короткое, живое, легко запоминается и одинаково подходит для крипты и акций. Имя уникально: `leeway-mcp` свободен в npm, токена LWAY нет на CoinGecko, MCP-проектов с таким названием на GitHub нет.

- Слоган: **"Give your agents leeway, not a private key."**
- Логотип «Drift»: два паруса (грот и стаксель), наклонённые ветром на 8°, над корпусом. Leeway — морской термин (снос судна под ветром): паруса = свобода, корпус = рамки, мачта и гик грота образуют букву L. Знак плоский и одноцветный, работает от 16 px до чеканки на монете; золото даёт материал, а не рисунок.
- Огромное слово в футере: **LEEWAY**.

Нарратив: *Agentic Economy* + *RWA / tokenized stocks*. Миллионы ИИ-агентов станут экономическими участниками на рынках крипты и акций, и им нужны институциональные рамки. Отсюда золото и «печать» в айдентике.

Токен **$LWAY** (концепт): стейкинг операторов MCP-нод, оплата премиум-тулов, governance. **sLWAY** — застейканный LWAY, получающий долю комиссий за tool-calls.

### Роадмап (7 фаз) и лестница листингов

1. Genesis (Q3 2026): сервер, тулы маркета и кошельков. ✅
2. Guardrails (Q4 2026): policy engine, риск-сканер, x402 quotes, docs, playground, swap_quote, simulate_tx ✓. Публикация в npm и MCP Registry подготовлена, ждёт запуска.
3. Wallets & Payments (Q4 2026 – Q1 2027) ⏳: горячий кошелёк агента с исполнением через policy (по умолчанию только тестнет) ✓, x402 settlement в USDC (v1 + v2) ✓, подтверждения через Telegram, CLI и admin HTTP ✓, Streamable HTTP для удалённых агентов ✓; дальше: ERC-4337 со scoped session keys, email-подтверждения, продажа ERC-20 с точным allowance, аудит #1.
4. **Equity Rails (Q1–Q2 2027)**: токенизированные акции, Parity Guard, мандаты для акций.
5. Token Generation (Q2 2027): аудит #2, TGE на Base, DEX (Uniswap v4, Aerodrome), LP lock 12 мес., CoinGecko/CMC.
6. Gateway Network (Q3 2027): ноды, fee share, Solana, CEX второго эшелона.
7. Agent Economy (Q4 2027+): маркетплейс агентов, CEX первого эшелона, SDK, governance.

Лестница листингов: аудит → TGE → DEX → агрегаторы/трекеры → Tier-2 CEX → Tier-1 CEX. Конкретные CEX не называть, всегда дисклеймер «планы, а не обещания».

## Визуальный референс

Тёмный премиальный крипто-лендинг (референс «Metaverse / IIC»): чёрный фон, золото, синий свет, 3D-объекты из полированного золота. Мы делаем **свой** бренд в этой стилистике, а не копию.

### Ключевые паттерны

1. **Двухтональные заголовки**: начало белое, последние слоги/слово уходят в серый градиент («A New Standard for Agent *Finance*»).
2. **Лейблы секций**: `[ OVERVIEW ]`, золотые, моно, 11px, letter-spacing .2em.
3. **Уголки-скобки**: у карточек L-образные уголки 10px по углам + тонкие крестики `+` на стыках сетки.
4. **Кнопки**: primary — золотой градиент, тёмный текст, uppercase 12px, ✦ иконка; secondary — прозрачная, золотая рамка 1px.
5. **Свет**: тёплое медно-розовое свечение слева сверху в hero, синий вертикальный луч через глобус, золотое свечение в CTA.
6. **Сетка** 1180px max, гаттер 16px на мобиле.

## Технические требования

- Статический сайт без сборки (деплой на GitHub Pages / Vercel в один клик): `index.html`, `styles.css`, `js/*.js` (ES-модули), Three.js локально.
- Все 3D-сцены: `MeshPhysicalMaterial` золото (metalness 1, roughness .15–.25, clearcoat) + `RoomEnvironment` PMREM. Рендер только когда секция в viewport (IntersectionObserver), DPR ≤ 2.
- Анимации появления: fade/translate + blur при скролле, stagger. `prefers-reduced-motion` выключает тяжёлое движение.
- Адаптив: 1440 / 1024 / 768 / 375. На мобиле глобус под текстом, меню-бургер.
- Lighthouse: семантика, alt, aria, контраст, meta/OG-теги.
- Без внешних картинок: всё 3D процедурное, иконки инлайн-SVG.

## Критерии готовности

- На скриншоте 1440px страница визуально на уровне референса: глубина, свет, 3D-золото, аккуратная типографика.
- Нет горизонтального скролла на 375px.
- 60 fps на среднем ноутбуке, нет ошибок в консоли.
