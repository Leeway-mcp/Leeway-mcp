What is Leeway MCP

Leeway is a Model Context Protocol server that turns any LLM into a capable on-chain operator. It exposes typed tools for market data, wallets, risk scans and x402 payments, and every spend goes through a policy engine, so agents can act and still can't spend past the limits you set.

  • Works with Claude Desktop, Cursor, Windsurf, OpenAI Agents
  • Read-only by default, writes need explicit policy
  • Self-host in one command, or use the hosted gateway

MCP infrastructure

Typed JSON-schema tools, streaming over stdio or HTTP, with idempotent calls, retries and full audit logs.

Agent intelligence

Risk models score every token and contract before your agent touches it: honeypots, hidden mints, holder concentration.

    [ Leeway Guard · Browser extension ]

    See What You Sign. Before Your Wallet Does.

    The same engine that guards AI agents, now in your browser. Leeway Guard reads every transaction and signature request on any dApp, simulates it on live chain state and tells you what will actually happen, before MetaMask or Rabby even opens.

    • Transaction firewall

      Every eth_sendTransaction is dry-run first: assets out and in, approvals, reverts, gas. Then you choose: reject, or continue to your wallet.

    • Signature firewall

      Decodes Permit and Permit2 signatures, the one-click drainer favourite. Flags unlimited amounts, plain-wallet spenders and long deadlines.

    • Scan any address

      Right-click a 0x… on X, Telegram Web or any DEX: Scan with Leeway returns a 0–100 token risk or the address reputation.

    • Local and private

      No account, no telemetry, never touches your keys. It reads the request before it reaches the wallet, and that's all.
