What is AURUM MCP

AURUM is a Model Context Protocol server that turns any LLM into a capable on-chain operator. It exposes typed tools for market data, wallets, risk scans and x402 payments, and every spend goes through a policy engine, so agents can act and still can't spend past the limits you set.

  • Works with Claude Desktop, Cursor, Windsurf, OpenAI Agents
  • Read-only by default, writes need explicit policy
  • Self-host in one command, or use the hosted gateway

MCP infrastructure

Typed JSON-schema tools, streaming over stdio or HTTP, with idempotent calls, retries and full audit logs.

Agent intelligence

Risk models score every token and contract before your agent touches it: honeypots, hidden mints, holder concentration.

Plug into any agent in 30 seconds

Drop AURUM into your MCP client config. Your agent picks up the tools on its own: no SDK, no glue code.

npx -y aurum-mcp
Read the docs →
claude_desktop_config.json 
{
  "mcpServers": {
    "aurum": {
      "command": "npx",
      "args": ["-y", "aurum-mcp"],
      "env": {
        "AURUM_DAILY_LIMIT_USD": "50",
        "AURUM_ALLOWLIST": "uniswap,aave",
        "AURUM_REQUIRE_APPROVAL": "true"
      }
    }
  }
}

    What Makes
    AURUM Different

    Policy-guarded wallets

    Daily limits, contract allowlists and human approval for anything above your threshold. Enforced server-side, so prompt injection can't get around them.

    x402 native payments

    Agents pay per request in USDC over HTTP 402. No API keys or subscriptions: machine-to-machine commerce that settles on-chain.

    Risk intelligence

    Honeypot detection, mint and blacklist function analysis, liquidity and holder concentration checks, all before a single wei moves.

    Open-source & self-hostable

    MIT licensed and written in TypeScript. Run it locally next to your agent, so your keys never leave your machine.
