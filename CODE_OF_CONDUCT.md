# Code of Conduct

We want Leeway to be a welcoming project for everyone, whatever their experience, background or identity.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback; critique code, not people.
- Help newcomers; everyone was new once.

## Not acceptable

- Harassment, insults, discriminatory language or personal attacks.
- Shilling, unsolicited token promotion, scams or phishing links in any project space.
- Sharing other people's private information without consent.

## Scope and enforcement

This applies to the repository, issues, pull requests, the Telegram group and other official Leeway spaces. Maintainers may remove content, warn, or ban participants who break these rules. Report problems privately to the maintainers at [support@leeway.icu](mailto:support@leeway.icu) or via [Telegram](https://t.me/leewaymcp).

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
