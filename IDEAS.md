# Идеи проектов: ИИ + MCP + крипта (ноябрь 2026)

## Выбрано: Mandate MCP ✅

MCP-сервер, через который ИИ-агенты получают доступ к ончейну, а траты ограничивает policy engine.

**Почему именно это:**
- Попадает сразу в три горячих нарратива: **Agentic Economy**, **MCP** (стандарт де-факто для подключения тулов к LLM) и **x402** (машинные микроплатежи по HTTP 402).
- Решает реальную боль: агенту нельзя просто отдать приватный ключ, prompt injection = слитый кошелёк. Guardrails на сервере понятны и разработчикам, и инвесторам.
- Есть работающий код уже сейчас: 9 тулов на живых данных, тест проходит. На GitHub это не пустой лендинг.
- Хорошо монетизируется: хостед-гейтвей, премиум-тулы через x402, стейкинг операторов нод (концепт $MNDT).

## Альтернативы (если захочется сменить фокус)

| # | Идея | Суть | Нарратив |
|---|---|---|---|
| 2 | **Rug Radar MCP** | Только безопасность: агент сканирует токены и контракты, объясняет транзакцию перед подписью | Security, AI-аудит |
| 3 | **Agent Bazaar** | Маркетплейс, где агенты продают друг другу услуги за x402 (данные, переводы, анализ) | Agent-to-agent commerce |
| 4 | **Onchain Memory MCP** | Долговременная память агента в IPFS/Arweave с ончейн-подписью: проверяемая история решений | Verifiable AI |
| 5 | **Alpha Copilot** | MCP для Telegram-ботов: агент следит за смарт-мани кошельками и присылает сигналы | Trading agents |
| 6 | **DAO Delegate Agent** | Агент читает пропозалы, суммирует и голосует по заданной политике | AI governance |

Все альтернативы можно встроить в Mandate как отдельные наборы тулов. Архитектура (тулы + policy engine) у них общая.
